# Conditional QA procedure

Add persistence/restart checks for durable mutations; fresh and upgrade-path checks for migrations; real Tauri/WebdriverIO only for a supported critical desktop journey; exploratory checks for plausible changed-flow failures; Deidara's visual matrix only for visible UI. Do not use foreground automation. If a required native/visual observation cannot run in the background, issue a human checklist and block until confirmed.

Use role/accessibility selectors and observable waits; never arbitrary sleeps. Record exactly what environment and layer each result proves.
