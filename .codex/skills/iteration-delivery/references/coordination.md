# Conditional coordination procedure

Use Treehouse only after explicit current authorization. Lease an isolated worktree, record its exact path and lease identity, and never return, destroy, prune, delete, push, create/update a PR, merge, or clean artifacts without another explicit authorization for that action.

For resumption, `delivery.md` is evidence, not a substitute for reality: reread it, inspect live task status, git/worktree state, and recorded checks. Stop on a mismatch and report it. Never create `AGENTS.md` for iteration state.
