# Conditional design references

Use WCAG 2.2 for interactive or accessibility-sensitive surfaces; NN/g for task flow, cognitive load, errors, or information architecture; Laws of UX for hierarchy/choice/feedback; Figma design-system guidance only when extending a reusable pattern. These are evidence, not product requirements.

Visual QA checks changed states in the running app: hierarchy, density, tokens, light/dark theme, focus/keyboard, empty/loading/error/success, overlays, and reduced motion. Mark material desktop changes for human QA and provide the exact checklist.
