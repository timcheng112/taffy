# Conditional planning checklists

Load only the relevant section: UI/navigation uses Deidara's handoff and V1 visual direction; persistence/scheduling/backups uses ADRs 0002, 0004, 0006, 0007 and real-database seams; cross-capability work uses Shikamaru's blueprint; frontend cache work uses the feature command-client/query contract.
