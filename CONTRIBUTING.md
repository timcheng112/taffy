# Contributing to Taffy

Taffy's Codex delivery crew is intentionally maintained outside this application repository in the private `taffy-agents` plugin. Install that plugin to use Naruto, Kakashi, Deidara, Sakura, Tsunade, Itachi, and Shino for Taffy work.

The application's iteration briefs, handoffs, and durable delivery records remain in `taffy-docs`; the agent runtime owns the orchestration behavior and local cmux workflow.
